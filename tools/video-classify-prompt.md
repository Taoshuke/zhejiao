给抖音收藏或喜欢的视频逐个分类。这是**视频分类**：按这一条视频讲的内容分，不按作者是谁、作者是哪国人、作者做什么职业来分。

每个视频只给一个分类，必须从下面 32 个里选（名称原样写）：

| 分类 | 收什么 |
|---|---|
| 人工智能 | AI 概念、大模型、AI 工具、智能体 |
| 编程开发 | 写代码、软件开发、开源项目 |
| 数码硬件 | 手机、电脑、相机等硬件，科技新闻 |
| 心理成长 | 心理学、亲密关系、自我成长 |
| 人生感悟 | 语录、感悟、情绪文案 |
| 哲学思想 | 哲学家、思想、思辨 |
| 历史人文 | 历史、宗教、文化 |
| 时事国际 | 时政、国际局势、战争、社会议题 |
| 财经投资 | 股票、经济、商业 |
| 科学科普 | 自然科学、地理、工程 |
| 语言学习 | 外语学习 |
| 读书文学 | 书单、文学、写作 |
| 职场求职 | 面试、职场、学业 |
| 法律常识 | 法律知识、案例 |
| 健康医疗 | 疾病、用药、养护 |
| 健身康复 | 健身动作、体态、康复训练 |
| 美食烹饪 | 做菜、探店、美食 |
| 音乐欣赏 | 歌曲、器乐、背景音乐 |
| 影视娱乐 | 电影解说、影视片段、明星 |
| 设计摄影 | 设计、配色、摄影、视觉创作 |
| 穿搭美妆 | 穿搭、美妆、发型 |
| 颜值写真 | 以展示外貌为主 |
| 幽默搞笑 | 段子、搞笑、整活 |
| 异国见闻 | 国外的生活、风土、见闻（只看内容，不看作者是哪国人） |
| 旅行风光 | 城市、风景、旅行 |
| 家居装修 | 装修、家居、买房 |
| 好物种草 | 商品推荐、带货、商家推广 |
| 体育赛事 | 体育比赛、格斗、运动员、体育技巧赛事 |
| 汽车出行 | 开车技巧、汽车、修车、买车 |
| 育儿教育 | 育儿、儿童教育、亲子 |
| 眼镜验配 | 验光配镜、眼镜加工 |
| 内容不明 | 没有文案也没有话题，看不出内容 |

判定细则：
- 以文案和话题标签为主，作者名为辅（作者名常能说明领域，但视频内容与之不符时按内容）。
- 一条视频涉及几个主题时，选它主要在讲的那个。用 AI 做设计、做视频的教程归人工智能；讲 AI 公司股价归财经投资。
- 只有歌名、歌词或「音乐分享」类文案的归音乐欣赏。
- 文案很短但有话题标签的，按标签判断；文案和标签都空才用内容不明。
- 内容明显集中在名单里没有的主题、且放进任何一类都很勉强时，写「新:」加四字主题（如 新:萌宠动物、新:游戏动漫），不要为零散内容造新主题。

只读写指定的本地文件，不联网、不打开浏览器、不运行访问网络的命令。
输出每行「id<TAB>分类」，不要表头；行数、id、顺序与输入完全一致。写完自查：行数一致、无重复无遗漏、分类都在名单里或以「新:」开头。
最后简短汇报：各分类计数；「新:」主题各列数量和两三个例子；拿不准的条目数量和两三个例子（id、文案片段、你给的分类、犹豫在哪两类之间）。
