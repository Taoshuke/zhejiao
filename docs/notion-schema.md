# Notion 数据库结构

网页与同步脚本按**列名**读写 Notion，列名要和下表一字不差（包括全角括号）。列的顺序、视图怎么排都随意，多出来的列不影响。

每个库的数据源 ID 填进 `src/platforms.mjs`。

## 抖音博主（`douyin.creators`）

| 列名 | 类型 | 说明 |
|---|---|---|
| 名称 | 标题 | 账号昵称 |
| 分类 | 单选 | 网页侧栏的分类；选项的顺序就是侧栏的「自定义顺序」，网页上拖动会改写它 |
| 主页链接 | 网址 | `https://www.douyin.com/user/<sec_uid>`，`tools/resync.py` 靠末尾的 sec_uid 对应账号 |
| 简介 | 文本 | |
| 头像 | 网址 | |
| 粉丝数 | 数字 | |
| 特别关注 | 勾选框 | |
| 已取关 | 勾选框 | |
| 取关日期 | 日期 | 带时间；「近期取关」按它排 |
| 关注日期 | 日期 | 带时间；「近期关注」「关注先后」按它排 |
| 关注顺序 | 数字 | 1 是最早关注的，越大越新；关注日期相同时按它排 |

`tools/resync.py` 新建行时还会写「平台」（单选，值为「抖音」）、「作品数」（数字）、「认证」（文本），不建这几列也不影响网页。

## 抖音收藏（`douyin.collect`）与抖音喜欢（`douyin.like`）

两个库各自独立，同一视频在两边各有一行，分类、取消各管各的。

| 列名 | 类型 | 说明 |
|---|---|---|
| 名称 | 标题 | 文案的开头一段 |
| 视频链接 | 网址 | `https://www.douyin.com/video/<id>` 或 `/note/<id>`，网页靠它把两个库的同一视频合成一条 |
| 文案 | 文本 | |
| 作者 | 文本 | |
| 作者主页链接 | 网址 | |
| 话题 | 文本 | |
| 发布时间 | 日期 | |
| 时长（秒） | 数字 | |
| 点赞数 | 数字 | |
| 类型 | 单选 | 「视频」或「图文」 |
| 分类 | 单选 | 两个库各有自己的分类选项 |
| 添加时间 | 日期 | 收藏或喜欢的时刻；「近期新增」按它排，导入的旧数据可以留空 |
| 取消日期 | 日期 | 填了就算取消，没有单独的勾选列 |

网页上改文字时写「名称」与「文案」两列。抖音的星标记在收藏夹库里（见下一节）；只在喜欢库里的视频标星时，也是在收藏夹库里加一行。

## 抖音收藏夹（`douyin.folders`）

一个视频放进一个收藏夹就是一行，标星就是放进名为「星标」的收藏夹。网页上放进收藏夹时，从收藏库那一行复制以下列过来：名称、作者、文案、话题、视频链接、作者主页链接、发布时间、时长（秒）、点赞数、类型。另外两列：

| 列名 | 类型 | 说明 |
|---|---|---|
| 收藏夹 | 单选 | 收藏夹名；要有一个叫「星标」的选项。网页上新建收藏夹就是给它加选项 |
| 添加时间 | 日期 | |

## 微信公众号文章（`wechat.articles`）

| 列名 | 类型 | 说明 |
|---|---|---|
| 名称 | 标题 | 与「标题」相同；网页改标题时两列一起写 |
| 标题 | 文本 | 卡片上显示的标题 |
| 公众号 | 文本 | 侧栏按它分类 |
| 链接 | 网址 | 原文地址；没有链接的不显示 |
| 收藏时间 | 日期 | 只到日 |
| 顺序 | 数字 | 收藏列表里的先后，1 是最早的；同一天的按它排 |
| 公众号待核 | 勾选框 | 可选；网页改公众号时会取消勾选 |
| 分类 | 单选 | 可选，按文章内容分的类；网页「内容」视图的侧栏按它分组，选项的顺序就是侧栏的顺序，没填的归到「未分类」 |

## X 博主（`x.creators`）

列和「抖音博主」相同。主页链接写 `https://x.com/<用户名>`；X 不提供关注时间，关注日期可以留空，先后靠「关注顺序」。分类选项可以单独定一套，网页侧栏只列有账号的分类。

## X 书签（`x.collect`）与 X 喜欢（`x.like`）

两个库各自独立，和抖音的收藏、喜欢一样。网页上把 `collect` 显示为「书签」。X 没有收藏夹库，星标直接记在两个库各自的「星标」列，网页上改文字时写「名称」与「正文」两列。

| 列名 | 类型 | 说明 |
|---|---|---|
| 名称 | 标题 | 正文的开头一段 |
| 帖子链接 | 网址 | `https://x.com/<用户名>/status/<id>`，网页靠它把两个库的同一帖子合成一条 |
| 正文 | 文本 | 引用了别的帖子时，可以把被引用的正文接在后面 |
| 作者 | 文本 | |
| 作者主页链接 | 网址 | |
| 发布时间 | 日期 | |
| 点赞数 | 数字 | |
| 类型 | 单选 | 「文字」「图片」或「视频」，网页暂时不用 |
| 分类 | 单选 | 两个库各有自己的分类选项 |
| 添加时间 | 日期 | 加书签或点喜欢的时刻；「近期新增」按它排，导入的旧数据可以留空 |
| 取消日期 | 日期 | 填了就算取消 |
| 星标 | 勾选框 | 网页上标星就是勾上它 |
| 顺序 | 数字 | 可选，1 是最早加的，方便在 Notion 里按加入先后排；网页不用 |

## 小红书博主（`rednote.creators`）

列和「抖音博主」相同。主页链接写 `https://www.xiaohongshu.com/user/profile/<用户 ID>`。分类选项可以单独定一套，网页侧栏只列有账号的分类。

## 小红书收藏（`rednote.collect`）与小红书点赞（`rednote.like`）

两个库各自独立，列和 X 的书签、喜欢相同，只有下面几列不一样。网页上把 `like` 显示为「点赞」，内容叫「笔记」。

| 列名 | 类型 | 说明 |
|---|---|---|
| 名称 | 标题 | 笔记标题；网页卡片上标题和正文接在一起显示 |
| 笔记链接 | 网址 | `https://www.xiaohongshu.com/explore/<笔记 ID>`，代替 X 的「帖子链接」，网页靠它把两个库的同一笔记合成一条 |
| 话题 | 文本 | 可选 |
| 类型 | 单选 | 「视频」或「图文」 |
