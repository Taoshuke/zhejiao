# Notion 数据库结构

网页与同步脚本按**列名**读写 Notion，列名要和下表一字不差（包括全角括号）。列的顺序、视图怎么排都随意，多出来的列不影响。

每个库的数据源 ID 填进 `src/platforms.mjs`。

## 抖音博主（`douyin.creators`）

| 列名 | 类型 | 说明 |
|---|---|---|
| 名称 | 标题 | 账号昵称 |
| 分类 | 单选 | 网页侧栏的分类；选项的顺序就是侧栏的「自定义顺序」，网页上拖动会改写它 |
| 主页链接 | 网址 | `https://www.douyin.com/user/<sec_uid>`，`tools/resync.py` 靠末尾的 sec_uid 对应账号 |
| 简介 | 文本 | |
| 头像 | 网址 | |
| 粉丝数 | 数字 | |
| 特别关注 | 勾选框 | |
| 已取关 | 勾选框 | |
| 取关日期 | 日期 | 带时间；「近期取关」按它排 |
| 关注日期 | 日期 | 带时间；「近期关注」「关注先后」按它排 |
| 关注顺序 | 数字 | 1 是最早关注的，越大越新；关注日期相同时按它排 |
| 子分类 | 单选 | 可选，分类下面的一级；每个账号最多一个。哪个子分类属于哪个分类以 `src/subcategories.mjs` 为准，Notion 的单选列表不记上下级。网页上改分类时，不属于新分类的子分类会被清掉 |
| 人工 | 勾选框 | 网页上改分类、子分类时自动勾上；`tools/notion_write.py` 跳过勾了它的行。你在 Notion 里也可以自己勾，取消勾选就是交还给脚本 |

`tools/resync.py` 新建行时还会写「平台」（单选，值为「抖音」）、「作品数」（数字）、「认证」（文本），不建这几列也不影响网页。

## 抖音收藏（`douyin.collect`）与抖音喜欢（`douyin.like`）

两个库各自独立，同一视频在两边各有一行，分类、取消各管各的。

| 列名 | 类型 | 说明 |
|---|---|---|
| 名称 | 标题 | 文案的开头一段 |
| 视频链接 | 网址 | `https://www.douyin.com/video/<id>` 或 `/note/<id>`，网页靠它把两个库的同一视频合成一条 |
| 文案 | 文本 | |
| 作者 | 文本 | |
| 作者主页链接 | 网址 | |
| 话题 | 文本 | |
| 发布时间 | 日期 | |
| 时长（秒） | 数字 | |
| 点赞数 | 数字 | |
| 类型 | 单选 | 「视频」或「图文」 |
| 分类 | 单选 | 两个库各有自己的分类选项 |
| 添加顺序 | 文本 | 加入先后，格式「2026-10-03 · 0001」：前面是批次日期，后面是四位编号，越晚加入编号越大。内容页默认按它排，「近期新增」取它最新的 99 条。网页上把一条加进另一个库时，写当天的批次、编号接着目标库现有的最大号 |
| 取消日期 | 日期 | 填了就算取消，没有单独的勾选列；「近期取消」取它最新的 99 条 |
| 星标 | 勾选框 | 网页上标星就是勾上它 |
| 人工 | 勾选框 | 网页上改分类时自动勾上，含义同博主库 |
| 添加时间 | 日期 | 可选，抖音的网页不用 |

网页上改文字时写「名称」与「文案」两列，同一条在两个库里的两行一起改。卡片上把一条加进另一个库时，从来源那一行复制新建，目标库里有的列照抄（含分类、星标），取消日期、添加顺序、添加时间不抄。

3.0 起不再使用「抖音收藏夹」库，星标改记在上面的「星标」列。

## 微信公众号文章（`wechat.articles`）

| 列名 | 类型 | 说明 |
|---|---|---|
| 名称 | 标题 | 与「标题」相同；网页改标题时两列一起写 |
| 标题 | 文本 | 卡片上显示的标题 |
| 公众号 | 文本 | 侧栏按它分类 |
| 链接 | 网址 | 原文地址；没有链接的不显示 |
| 收藏时间 | 日期 | 只到日 |
| 顺序 | 数字 | 收藏列表里的先后，1 是最早的；同一天的按它排 |
| 公众号待核 | 勾选框 | 可选；网页改公众号时会取消勾选 |
| 分类 | 单选 | 可选，按文章内容分的类；网页「内容」视图的侧栏按它分组，选项的顺序就是侧栏的顺序，没填的归到「未分类」 |
| 人工 | 勾选框 | 网页上改分类时自动勾上，含义同博主库 |

## X 博主（`x.creators`）

列和「抖音博主」相同。主页链接写 `https://x.com/<用户名>`；X 不提供关注时间，关注日期可以留空，先后靠「关注顺序」。分类选项可以单独定一套，网页侧栏只列有账号的分类。「人工」列也要建；「子分类」只在 `src/subcategories.mjs` 给这个平台写了子分类时才需要。

## X 书签（`x.collect`）与 X 喜欢（`x.like`）

两个库各自独立，和抖音的收藏、喜欢一样。网页上把 `collect` 显示为「书签」。星标记在两个库各自的「星标」列，网页上改文字时写「名称」与「正文」两列。

| 列名 | 类型 | 说明 |
|---|---|---|
| 名称 | 标题 | 正文的开头一段 |
| 帖子链接 | 网址 | `https://x.com/<用户名>/status/<id>`，网页靠它把两个库的同一帖子合成一条 |
| 正文 | 文本 | 引用了别的帖子时，可以把被引用的正文接在后面 |
| 作者 | 文本 | |
| 作者主页链接 | 网址 | |
| 发布时间 | 日期 | |
| 点赞数 | 数字 | |
| 类型 | 单选 | 「文字」「图片」或「视频」，网页暂时不用 |
| 分类 | 单选 | 两个库各有自己的分类选项 |
| 添加顺序 | 文本 | 加入先后，格式与抖音相同；内容页默认按它排，「近期新增」取它最新的 99 条 |
| 添加时间 | 日期 | 加书签或点喜欢的时刻，导入的旧数据可以留空；网页上恢复一条取消的内容时填此刻 |
| 取消日期 | 日期 | 填了就算取消 |
| 星标 | 勾选框 | 网页上标星就是勾上它 |
| 人工 | 勾选框 | 网页上改分类时自动勾上，含义同博主库 |
| 顺序 | 数字 | 可选，1 是最早加的，方便在 Notion 里按加入先后排；网页不用 |

## 小红书博主（`rednote.creators`）

列和「抖音博主」相同。主页链接写 `https://www.xiaohongshu.com/user/profile/<用户 ID>`。分类选项可以单独定一套，网页侧栏只列有账号的分类。「人工」与「子分类」两列同 X 博主。

## 小红书收藏（`rednote.collect`）与小红书点赞（`rednote.like`）

两个库各自独立，列和 X 的书签、喜欢相同，只有下面几列不一样。网页上把 `like` 显示为「点赞」，内容叫「笔记」。

| 列名 | 类型 | 说明 |
|---|---|---|
| 名称 | 标题 | 笔记标题；网页卡片上标题和正文接在一起显示 |
| 笔记链接 | 网址 | `https://www.xiaohongshu.com/explore/<笔记 ID>`，代替 X 的「帖子链接」，网页靠它把两个库的同一笔记合成一条 |
| 话题 | 文本 | 可选 |
| 类型 | 单选 | 「视频」或「图文」 |

## 豆瓣读书（`douban.books`）

一本书一行。网页上能改的只有「星标」「短评」「取消日期」三列，别的列在 Notion 里改，改完点「从 Notion 同步」。「近期新增」按 Notion 行的创建时间取最新的 99 本，不需要单独的列。

| 列名 | 类型 | 说明 |
|---|---|---|
| 书名 | 标题 | |
| 豆瓣链接 | 网址 | `https://book.douban.com/subject/<条目编号>/`，同步脚本从中取出条目编号，封面、详情资料与详情页网址都用它 |
| 出版信息 | 文本 | 豆瓣条目上那一行，形如「[英] 某作者 / 某译者 / 某出版社 / 2024-5 / 59.00元」，段数不固定。同步脚本从中拆出作者、译者、出版社、出版年，定价不留；书架按出版社分组就用这里拆出的出版社 |
| 短评 | 文本 | 网页详情页上写、改、删，最多 350 字，写空即清空 |
| 分类 | 多选 | 书架「分类」分组用，一本书可以有几个；语种类（比如「英文」）也放在这里。选项的顺序就是侧栏的顺序 |
| 专题 | 多选 | 可选，按内容归纳的细主题；书架「专题」分组与详情页下方的同专题书用它，没填的书不进任何专题组 |
| 星标 | 勾选框 | 网页上标星就是勾上它 |
| 取消日期 | 日期 | 填了就算取消，取消了的书只在「近期取消」里出现 |

封面放在 `public/covers/douban/<条目编号>.jpg`，没有的按书名生成书封；补了封面要再同步一次，数据里才标出。详情页的资料（丛书、副标题、原作名、评分、内容简介、目录等）放在 `public/details/douban/<条目编号>.json`，随网页部署，没有文件的书只显示书架上已有的几项。

## 豆瓣影视（`douban.movies`）

一部影片一行，除下面两列外，其余列和「豆瓣读书」同名同义（豆瓣链接、短评、分类、专题、星标、取消日期）。库可以是空的，网页显示空状态。

| 列名 | 类型 | 说明 |
|---|---|---|
| 片名 | 标题 | 代替「书名」 |
| 出品信息 | 文本 | 代替「出版信息」，写成「导演 / 主演 / 年份 / 地区」，导演、主演多人用顿号分隔，形如「某导演 / 某演员、另一演员 / 2019 / 法国」。年份是四位数字，前面两段依次是导演、主演，后面的是地区；合导的片子在每位导演的分组下各出现一次 |

海报放在 `public/covers/douban-movie/<条目编号>.jpg`，详情资料放在 `public/details/douban-movie/<条目编号>.json`，规则同书。
